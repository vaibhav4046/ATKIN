1. **Gap 1 (Persistence)**: Wire `Dexie` IndexedDB database to auto-hydrate and auto-save on all matter, document, claim, draft, and review changes so user work permanently survives refreshes.
2. **Gap 2 (Real Microphone Dictation)**: Upgrade simulated voice intake in `ChatTab` to use real `navigator.mediaDevices.getUserMedia` / browser Web Speech API with audio recording visualization.
3. **Gap 3 (Design System Tokens & 30 Anti-Template Rules)**: Align CSS variables and Tailwind classes with the quiet legal workspace palette (#F5F5F7, #FFFFFF, #ECEDEF, #1D1D1F, #565861, #0066CC), eliminate all large card radii, and ensure no template AI decoration exists.
4. **Gap 4 (Legal Surfaces & Terms)**: Add accessible Terms of Service, Privacy Policy, Sovereign Storage architecture docs, and release checklist.
